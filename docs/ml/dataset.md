# Data Sheet

## Общая информация

**Название датасета:** MS MARCO — Microsoft MAchine Reading COmprehension.

**Источник:** [страница MS MARCO на Hugging Face](https://huggingface.co/datasets/microsoft/ms_marco).

**Создатель:** Microsoft.

**Язык:** английский.

**Назначение:** задачи поиска, ранжирования текстов, вопросов и ответов. В `multilingual-e5-small` этот датасет использовался на втором этапе обучения модели.

**Лицензия:** не указана в карточке датасета на Hugging Face. На официальной странице Microsoft для скачивания предложено принять условия использования.

MS MARCO — только один из датасетов модели. Кроме него, авторы использовали многоязычные и другие англоязычные наборы данных.

## Состав данных

**Объём:** полная версия, описанная в статье, содержит:

- 1 010 916 обезличенных поисковых запросов Bing;
- 182 669 полностью переписанных человеком ответов;
- 8 841 823 текстовых отрывка;
- отрывки получены из 3 563 535 веб-документов.

На Hugging Face версия `v2.1` разделена так:

| Часть | Количество записей |
| --- | ---: |
| Обучающая (`train`) | 808 731 |
| Проверочная (`validation`) | 101 093 |
| Тестовая (`test`) | 101 092 |
| **Всего** | **1 010 916** |

Для дополнительного обучения `multilingual-e5-small` авторы модели использовали 500 тыс. пар MS MARCO Passage и 70 тыс. пар MS MARCO Document. Это часть полного датасета.

**Тип данных:** английские текстовые запросы, найденные веб-отрывки и ответы людей.

**Основные поля / признаки:**

| Поле | Что содержит |
| --- | --- |
| `query_id` | ID поискового запроса |
| `query` | Текст запроса |
| `query_type` | Тип запроса: место, число, человек, описание или объект |
| `passages` | До десяти найденных текстовых отрывков |
| `passages.passage_text` | Текст отрывка |
| `passages.url` | Адрес исходной веб-страницы |
| `passages.is_selected` | Использовал ли эксперт этот отрывок для ответа: `1` или `0` |
| `answers` | Ответы, написанные экспертами |
| `wellFormedAnswers` | Ответы, переписанные в понятной форме без дополнительного контекста |

## Получение данных

По описанию Microsoft данные собирались так:

1. Из журналов Bing выбирались реальные запросы пользователей.
2. Запросы фильтровались и обезличивались.
3. Bing находил до десяти подходящих веб-отрывков для каждого запроса.
4. Эксперты читали запросы и отрывки, отмечали полезные отрывки и писали ответы своими словами.
5. Часть ответов дополнительно проверялась и переписывалась так, чтобы быть понятной без исходного отрывка.

Имена и состав группы экспертов авторами не указаны.

## Предобработка

До публикации запросы были отфильтрованы и обезличены. Веб-документы разделили на отдельные отрывки, а эксперты отметили подходящие отрывки полем `is_selected`.

Исходные версии предоставлялись в JSON или JSONL. На Hugging Face данные автоматически переведены в формат Parquet и разделены на `train`, `validation` и `test`.

Дополнительная очистка именно для обучения `multilingual-e5-small` подробно не описана. В техническом отчете сказано, что для дополнительного обучения использовалась только обучающая часть размеченных датасетов.

## Ограничения

1. MS MARCO — англоязычный датасет, а основной язык нашего проекта — русский.
2. Данные основаны на веб-поиске Bing, а не на интересах читателей и описаниях книг.
3. Состав запросов зависит от пользователей Bing и работы поисковой системы в период сбора данных.
4. Веб-страницы могут содержать ошибки, устаревшую информацию и неравномерно представлять разные темы.
5. В карточке датасета на Hugging Face нет готового анализа смещений, этических рисков и персональных данных. Доступной информации недостаточно для их полной оценки.
6. Лицензия на странице Hugging Face не указана; перед реальным использованием нужно проверить условия Microsoft.

## Использование в проекте

MS MARCO не загружается в библиотечную систему и не содержит наш каталог. Он уже использовался авторами для обучения модели сопоставлять запрос с подходящим текстом.

Связь с проектом такая:

- `query` похож на текст интересов читателя;
- `passage_text` похож на название, жанры и аннотацию книги;
- `is_selected` показывает, подходит ли текст запросу.

Однако поисковый запрос и интерес к книге — не одно и то же. Поэтому перед реальным запуском модель нужно отдельно проверить на небольшом наборе русскоязычных примеров из нашего каталога. Для каждой проверки человек должен указать, какие книги действительно подходят заданным интересам.
