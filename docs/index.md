# Моя документация

АС «УВК» — автоматизированная система «Учет и выдача книг» с возрастной фильтрацией и проектируемым ML-модулем рекомендаций.

## О проекте

Документация хранится в Git и создаётся с помощью MkDocs.

- В практикуме 1 настроена среда Docs as Code.
- В практикуме 2 подготовлены описание библиотечной системы, требования и UML-диаграммы.
- В практикуме 3 описаны восемь операций API в OpenAPI 3.0.3.
- В практикуме 4 выбрана модель `multilingual-e5-small`, описаны MS MARCO, ограничения и риски.

[Описание API и Swagger UI](api/index.md) содержат запросы, ответы, ошибки и переиспользуемые схемы. В разделе [«ML-модель»](ml/model-card.md) находятся Model Card, Data Sheet и анализ рисков.
