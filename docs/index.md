# Моя документация

АС «УВК» — автоматизированная система «Учет и выдача книг» с возрастной фильтрацией и проектируемым ML-модулем рекомендаций.

## О проекте

Документация хранится в Git и создаётся с помощью MkDocs. В практикуме 1 настроена среда Docs as Code, в практикуме 2 подготовлены описание библиотечной системы, требования и UML-диаграммы, а в практикуме 3 описаны восемь операций API в OpenAPI 3.0.3.

[Описание API и Swagger UI](api/index.md) содержат запросы, ответы, ошибки и переиспользуемые схемы, включая администратора и библиотекаря.
