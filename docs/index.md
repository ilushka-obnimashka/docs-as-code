# Моя документация

Документация системы учета и выдачи книг с возрастной фильтрацией и проектируемым ML-модулем рекомендаций.

## О проекте

Документация хранится в Git и создаётся с помощью MkDocs. В практикуме 1 настроена среда Docs as Code, а в практикуме 2 подготовлены описание библиотечной системы, требования и UML-диаграммы.

Начни с [описания проекта](project/overview.md), затем перейди к [User Stories и Use Case](project/requirements.md) и [диаграммам последовательности и классов](project/diagrams.md).
