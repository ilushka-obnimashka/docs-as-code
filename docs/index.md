# Моя документация

АС «УВК» — автоматизированная система «Учет и выдача книг» с возрастной фильтрацией и проектируемым ML-модулем рекомендаций.

## О проекте

Документация хранится в Git и создаётся с помощью MkDocs. В практикуме 1 настроена среда Docs as Code, а в практикуме 2 подготовлены описание библиотечной системы, требования и UML-диаграммы.
